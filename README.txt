Лабораторная работа №1: поразрядные и логические операции.
Вариант: X = 5, Y = 15.
Тип числа: uint16_t.
Преобразование: симметричные байты меняются местами в обратном порядке.

Сборка:
    make all

Запуск:
    ./prg1 128
    ./prg1

Проверка:
    make test

Очистка:
    make clean

Пример:
    ./prg1 0
    00000000 00000000
    00000000 00000000

Если передан нечисловой аргумент, программа печатает сообщение в stderr
и завершается с ошибкой.
