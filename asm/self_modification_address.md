Теперь по документации видно, как это работает. В Simple CPU нет косвенной адресации через регистр, поэтому используем самомодификацию команды. Но сначала разберём принцип на конкретном примере.

Допустим, в памяти записано:

```
@0xFE = 0xD0
@0xD0 = 0x42
```

### Шаг 1. Считываем адрес

```
r0 <- @0xFE
```

Теперь `R0 = 0xD0`.

### Шаг 2. Читаем значение по адресу `0xD0`

Предположим, команда чтения находится по адресу `0x10`:

```
        r1 <- @0x00
```

Она занимает два байта:

| Адрес  | Содержимое                        |
| ------ | --------------------------------- |
| `0x10` | код команды `r1 <- @...`          |
| `0x11` | адрес операнда, изначально `0x00` |

Чтобы команда прочитала данные из `0xD0`, нужно записать `0xD0` в ячейку `0x11`.

Но команда записи в память принимает фиксированный адрес, поэтому нужно использовать ещё один приём: расположить адресный байт команды в заранее известном месте и изменить его посредством команды записи в память.

Например, если `R0 = 0xD0`, можно было бы написать:

```
@0x11 <- r0
```

Однако здесь есть тонкость: эта команда запишет в `0x11` значение `0xD0` только в том случае, если адрес операнда чтения действительно находится в `0x11`.

### Главное

Для твоей задачи последовательность будет такой:

1. Считать адрес из `0xFE` в регистр.
2. Увеличить адрес на единицу.
3. Записать текущий адрес в байт операнда команды чтения.
4. Выполнить команду чтения, чтобы получить значение из нужной ячейки.
5. Сравнить значение с `0xFF`, увеличить счётчик совпадений при равенстве.
6. Повторить 16 раз.
7. Записать счётчик в `0xFF` и остановиться.

Важно: в примере выше адрес `0x11` условный. В твоей программе нужно подставить фактический адрес байта операнда после сборки кода.
