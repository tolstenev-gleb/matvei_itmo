# Лабораторная работа №1
## Поразрядные и логические операции

Разработать на языке C для ОС Linux программу, которая получает целое число типа uint16_t, выводит его двоичное представление на экран (необходимо выводить все разряды числа, байты числа разделяются пробелами), выполняет преобразование в соответствии с вариантом, затем выводит на экран двоичное представление результата преобразования.

Вариант:
Назовем симметричным байт, в котором нулевой бит имеет такое же значение, что и седьмой, а первый – такое же, что и шестой. Изменить порядок следования симметричных байтов в числе на обратный.

Пример для uint32_t:
```text
0xDEADBEEF ->
0xDEEFBEAD

11011110 10101101 10111110 11101111 ->
11011110 11101111 10111110 10101101
```

При запуске программы пользователь может указать число в десятичной системе счисления, в этом случае преобразование осуществляется над указанным числом. Например
(тип числа — short, преобразование — инверсия всех битов):
```bash
$ ./prg1psiN31451 128
00000000 10000000
11111111 01111111
```

Алгоритм преобразования должен быть реализован таким образом, чтобы, во-первых, он не был жестко "завязан" на размер числа (то есть чтобы он не "ломался" при замене типа на другой), и, во-вторых, был отделен от кода, выводящего число на консоль (например, реализован в виде отдельной функции).

Если пользователь при запуске указывает вместо числа нужного формата строку, которая не является числом, программа должна сообщить об ошибке:

```bash
$ ./prg1psiN31451 щито
Ошибка: 'щито' не является числом.
$ ./prg1psiN31451 220v
Ошибка: '220v' не является числом.
```

Если пользователь не указывает число при запуске, программа должна получить случайное число с помощью функций стандартной библиотеки srand() и rand(). Например:

```bash
$ ./prg1psiN31451
00000001 01011001
11111110 10100110
```

Проект (исходные коды, заголовочные файлы, Makefile и прочие файлы, которые могут понадобиться для сборки) должен содержаться в отдельном каталоге с именем, совпадающим с названием программы (prg1abcNXXXXX), и собираться с помощью стандартной утилиты make. Исходные файлы программы на языке C должны компилироваться с помощью gcc. Makefile должен поддерживать как минимум цели all и clean. Пример заготовки проекта содержится в файле prg1.c, Makefile, README.txt.
